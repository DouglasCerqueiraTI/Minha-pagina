# 💡 Minha Página — Interruptor Interativo

Projeto web introdutório desenvolvido para praticar a integração entre HTML5, CSS3 e JavaScript puro, além da publicação e hospedagem estática utilizando o GitHub Pages.

🔗 **Acesse o projeto online:** [https://douglascerqueirati.github.io/Minha-pagina/](https://douglascerqueirati.github.io/Minha-pagina/)

---

## 🚀 Funcionalidades

- **Interatividade com JavaScript:** Botão que altera dinamicamente o estado visual e o texto da página por meio de estruturas condicionais (`if/else`)[cite: 4].
- **Separação de Responsabilidades:** Organização limpa do código dividindo estrutura (`index.html`), estilização (`estilo.css`) e comportamento (`script.js`) em arquivos independentes[cite: 1, 4].

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica dos elementos da página.
- **CSS3:** Estilização e controle visual dos estados da interface.
- **JavaScript:** Manipulação do DOM e controle de eventos de clique[cite: 1].
- **GitHub Pages:** Hospedagem gratuita diretamente a partir da branch `main`[cite: 2, 3].
